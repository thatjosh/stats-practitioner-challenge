# Comparative Analysis of Log Returns Prediction Using fBM, GARCH-fBM, and GARCH

This repository provides a comparative study of three different approaches for predicting S&P500 log returns:
1. **Fractional Brownian Motion (fBM)** in Python
2. **Combined GARCH-fBM** in Python
3. **Traditional GARCH** in R

## Repository Structure

```
.
├── README.md             # Project overview and instructions (this file)
├── fBM.ipynb             # Jupyter notebook that runs fBM experiments
├── GARCH-fBM.ipynb       # Jupyter notebook that runs GARCH-fBM experiments
├── utils.py              # Utility methods for models
├── plots.py              # Utility methods for plots
├── diagnostics.py        # Utility methods for model diagnostics
├── garch_model.Rmd       # R script implementing GARCH
└── data/
```
